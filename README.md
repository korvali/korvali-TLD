# ⚡ Korvali TLD List Generator

> A minimal, zero-dependency Python script to scrape root zone databases and generate clean, responsive static HTML pages for TLD & ccSLD lookup.

---

## 🔗 Official Network

- **Official Website**: [Korvali](https://www.korvali.net)
- **Live Demo Engine**: [tld.korvali.net](https://tld.korvali.net)
---

## 🎯 Features

- **🐍 Zero-Dependency Python**: Built using standard `urllib` & `html.parser` — runs on any Python 3.x environment without `pip install`.
- **🔍 Suffix-Based Filtering**: Filter domain extensions dynamically by suffix (e.g., `e`, `io`, `ai`, `id`).
- **🌐 Built-in ccSLD Data**: Includes predefined popular country-code second-level domains (`.co.id`, `.com.au`, `.org.uk`, etc.).
- **🚀 Clean URL SEO**: Generates production-ready HTML with pre-configured Canonical URLs, Open Graph, Twitter Cards, and Schema.org JSON-LD.
- **📱 Fully Responsive**: Outputs standalone HTML with Flexbox layout, white-space wrapping, and custom scroll overrides.
